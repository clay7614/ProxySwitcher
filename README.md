# ProxySwitcher

![Platform-Windows](https://img.shields.io/badge/Platform-Windows-blue.svg)
![Framework-.NET9](https://img.shields.io/badge/Framework-.NET%209-purple.svg)

**ProxySwitcher** は、Windows のプロキシ設定をタスクトレイから切り替えられる、軽量な常駐型アプリケーションです。

## 特徴

- **ワンクリック切り替え**: タスクトレイのアイコンから、プロキシの ON/OFF を即座に切り替え。
- **WiFi SSID 連動**: 特定の WiFi に接続した際に自動でプロキシを ON にし、それ以外では OFF にする自動化機能を搭載。
- **グローバルホットキー**: `Ctrl + Alt + P` でどこからでも素早く切り替え。
- **視覚的なフィードバック**: プロキシの状態に合わせてタスクトレイアイコンが変化（緑：ON、赤：OFF）。
- **自動起動**: Windows スタートアップへの登録に対応。
- **超軽量**: システムリソースをほとんど使用せず、高速に動作。

## 使い方

### 1. 準備
- ブラウザによるブロックを避けるため、リリースは **ZIP形式** で配布しています。
- ダウンロードした ZIP を展開し、中の `ProxySwitcher.exe` を任意の場所に配置して実行してください。
- 軽量版 (`Lightweight.zip`) を使用する場合のみ、**.NET 9 ランタイム**が必要です。


### 2. 基本的な操作
- **プロキシの切り替え**: 
  - タスクトレイアイコンを右クリック → 「プロキシをON/OFFにする」を選択。
  - または、ホットキー `Ctrl + Alt + P` を押す。
- **設定の変更**:
  - タスクトレイアイコンを右クリック → 「設定」を選択。
  - プロキシサーバーのアドレス（例: `proxy.example.com:8080`）を入力して保存。

### 3. WiFi 自動連動の設定
- 設定画面で「対象のWiFi SSID」を入力し、「このWiFi接続時にプロキシを自動ONにする」にチェックを入れて保存してください。
- 指定した SSID に接続されると自動的にプロキシが有効になり、切断または別のネットワークに接続されると自動的に無効になります。

## システム要件

- **OS**: Windows 10 / 11
- **ランタイム**: .NET 9
